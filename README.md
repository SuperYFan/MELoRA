# MELoRA: Modular Expert LoRA Fusion for Low-Resource Chinese Harmful Meme Detection

Code and processed data for **MELoRA**, a framework for low-resource Chinese harmful meme detection.
MELoRA converts meme images into textual evidence through visual verbalization, trains three LoRA experts
on auxiliary tasks (harmful semantics, harmful meme reasoning, and visual expression understanding), and
fuses the frozen experts with token- and projection-level routers. Only the routers are calibrated on the
few labeled target examples.

> **Content warning.** The data contain harmful, offensive, and discriminatory memes and texts. They are
> released for research on harmful content detection only.

## Repository structure

```
MELoRA/
├── src/                         # Python source code
│   ├── moe_lora.py              # token- and projection-level fusion routers (MELoRA core)
│   ├── lora_learning.py         # router calibration and evaluation
│   ├── zh_lora_composition.py   # entry point: calibrate routers over frozen experts
│   ├── main.py, train.py        # entry point: train a single LoRA expert
│   ├── zh_modular_dataset.py    # unified instruction-format data loader
│   ├── zh_fewshot_dataset.py    # K-shot / ratio sampling of the target support set
│   ├── zh_modular_gen_eval.py   # AUC / ACC evaluation on the target benchmarks
│   ├── zh_router_analysis.py    # expert-weight analysis (Figures 4 and 5)
│   ├── generate_*.py            # visual verbalization (image descriptions with Qwen3-VL)
│   ├── *_fewshot_baseline.py    # VLM in-context few-shot baselines
│   ├── qwen3vl/                 # Qwen3-VL based baselines
│   └── ...
├── scripts/                     # shell scripts that reproduce the experiments
└── data/zh_modular/             # processed data used in the paper (unified instruction format)
    ├── schema.json
    ├── benchmarks/
    │   ├── toxicn_mm/           # ToxiCN-MM train / test
    │   └── sarcnet/             # SarcNet (Chinese subset) train / dev / test
    └── modules/
        ├── hate_semantics/              # M1, from ToxiCN
        ├── met_m3_toxicn_reasoning/     # M2 for ToxiCN-MM, MET-Meme + M3-Weibo
        ├── met_m3_sarcnet_reasoning/    # M2 for SarcNet,   MET-Meme + M3-Weibo
        └── visual_expression/           # M3, from emo-visual-data
```

Every record follows `schema.json` (`id`, `instruction`, `input`, `output`, `text`, `label`, `metadata`).
The `input` field already contains the image description generated by Qwen3-VL-8B-Instruct, so the
experiments run on these files directly and do not need the images. The M2 data are provided in two
versions, each deduplicated against the test set of the corresponding target benchmark. The original
datasets and images are not included in this repository; please obtain them from the sources listed in
[Data sources](#data-sources).

## Installation

```bash
conda create -n melora python=3.10 -y
conda activate melora
pip install -r requirements.txt
```

Download the backbone [Qwen2.5-7B](https://huggingface.co/Qwen/Qwen2.5-7B) to `models/Qwen2.5-7B`
(or pass its location with `BASE_MODEL=...`), and [Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct)
if you want to regenerate the image descriptions.

Scripts that call a VLM API (`generate_*.py`, `api_fewshot_baseline.py`, `hf_internvl_fewshot_baseline.py`)
take the endpoint and the key as command-line arguments, for example:

```bash
python src/generate_lora3_visual_inputs.py --api_url <endpoint> --api_key <key> --model <model>
```

Any OpenAI-compatible chat-completions endpoint that accepts image input can be used. The image
descriptions of this release were generated with `Qwen/Qwen3-VL-8B-Instruct`.

## Usage

All commands are run from the repository root.

**1. Train the three LoRA experts**

```bash
DATA_ROOT=data BASE_MODEL=models/Qwen2.5-7B OUT_ROOT=lora_modules bash scripts/zh_module_train.sh
```

This trains M1 (Harmful Semantics), the two benchmark-specific versions of M2 (Harmful Meme Reasoning,
for ToxiCN-MM and for SarcNet), and M3 (Visual Expression).

**2. Calibrate the routers on K labeled target examples and evaluate**

```bash
python src/zh_lora_composition.py \
  --DATASET zh-toxicn-mm --PATH data --base_model models/Qwen2.5-7B \
  --lora_dir lora_modules \
  --lora_modules zh_hate_semantics/<ckpt>,zh_met_m3_toxicn_reasoning/<ckpt>,zh_visual_expression/<ckpt> \
  --num_shots 16 --SEED 1111 \
  --composition_method moe --moe_top_k 3 --moe_router_type mlp --moe_router_hidden_size 128 \
  --moe_router_granularity token --moe_router_lr 1e-3 --moe_router_epochs 20 --moe_temperature 1.0 \
  --eval_split test --POS_WORD 否 --NEG_WORD 是 --save_case_study --case_study_dir predictions
```

`--num_shots` is the number of examples **per class**, so `--num_shots 16` corresponds to K = 32.
Use `--DATASET zh-sarcnet` for SarcNet, and `--calibration_ratio 0.05` (instead of `--num_shots`) for the
target-data-ratio experiments. `scripts/run_melora_5seed_predictions.sh` runs all budgets and the five seeds
(1111, 2222, 3333, 4444, 5555).

**3. Additional experiments and analysis**

| Experiment | Script |
|---|---|
| Target-data ratios | `scripts/zh_calibration_ratio.sh` |
| Expert-weight analysis | `src/zh_router_analysis.py` |
| Computational cost | `scripts/run_cost_measurement.sh` |

## Data sources

The processed data are derived from the following public datasets. The original data and images are not
redistributed here; please download them from the original sources, follow their licenses and terms of
use, and cite the corresponding papers.

| Dataset | Use in MELoRA | Reference |
|---|---|---|
| ToxiCN-MM | target benchmark | Lu et al., *Towards Comprehensive Detection of Chinese Harmful Memes*, NeurIPS 2024 |
| SarcNet (Chinese subset) | target benchmark | Yue et al., *SarcNet: A Multilingual Multimodal Sarcasm Detection Dataset*, LREC-COLING 2024 |
| ToxiCN | training data of M1 | Lu et al., *Facilitating Fine-grained Detection of Chinese Toxic Language*, ACL 2023 |
| MET-Meme | training data of M2 | Xu et al., *MET-Meme: A Multimodal Meme Dataset Rich in Metaphors*, SIGIR 2022 |
| M³ (Weibo subset) | training data of M2 | Xing et al., *Is AI Ready for Multimodal Hate Speech Detection? A Comprehensive Dataset and Benchmark Evaluation*, arXiv:2603.21686, 2026 |
| emo-visual-data | training data of M3 | LLM-Red-Team, *Emo Visual Data*, https://github.com/LLM-Red-Team/emo-visual-data, 2024 |
